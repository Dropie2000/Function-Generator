# Function Generator

## Overview
This repository contains the code for a funtion generator that works within the Mc Pic18F4550, and an analog module as the MCP4725 that produces an analog output, communicating with the microcontroller via I2C

## Objective
Whats required is to generate an output signal that follows the shape of some characteristic functions, as square, sawtooth, triangular and sinusoidal.
The communication with the analog module is through I2C and the selection of the signal is through RS232 by tapping a key.

## Devices
- PIC18F4550
- MCP4725 Analog module
- FT232RL Module
